# PylaAI panel design

Approved by the user: dark graphite surfaces, a restrained yellow accent inspired by Brawl Stars, colorful existing brawler portraits, larger readable text, quiet navigation, no violet gradients or glows. Preserve the four-step setup, all profiles, functionality, section order and Russian interface language.

Product: local emulator, account and brawler-queue control.
Character: focused, playful, precise.
World: a game roster and its control desk.
Moments: brawler portraits and the current roster.
Signature: a consistent profile number beside its device and queue.

Approaches: a cosmetic patch would retain inconsistent spacing and type; a full framework rewrite would add unnecessary risk. Refresh the existing Flask/vanilla HTML/CSS/JS presentation in place. Retain API paths, event delegation, control IDs and process lifecycle. Use local SVG icons and system fonts without external requests.

Scope: CSS, static icons, template chrome and presentation strings. Do not alter backend execution, account storage, API authentication or game logic. Use actual catalog or queue data for the roster visual, with a label distinguishing them. No generated images, invented match statistics, or video.

Validation: existing Python and JS checks; browser inspection of desktop dashboard and mobile queue; keyboard focus and overflow checks; verify all four setup steps and controls remain available without starting a game. Review and publish to the already authorized GitHub repository.

Craft workflow informed by unslop, Damir Sokolovsky (@heydamir), CC BY 4.0: https://heydamir.design/unslop

## Implementation report

1. Spacing: consistent 4px rhythm, 24px panel padding and aligned rows; compact desktop navigation and 44px mobile controls.
2. Color: graphite surface steps, three text roles, yellow selection/primary action, semantic state colors; removed violet surfaces, gradients and glows.
3. Icons: one local 18px/1.5px SVG set; accessible names retained for icon buttons.
4. Copy: concrete page names and queue-focused overview; sentence-case labels replace uppercase captions and vague headlines.
5. Type: OS Segoe UI stack, weights 400/500, larger labels, tabular figures and monospace profile/device metadata.
6. Layout: 256px desktop sidebar, fluid content, responsive forms and horizontal table scrolling inside its container; section order and wizard retained.
7. Details: nested control/card radii, quiet counts, consistent profile numbers and visible 2px keyboard focus.
8. Visuals: colorful existing brawler portraits on calm surfaces. Overview portraits are explicitly labeled as catalog entries, never as a user's selected queue. No generated images or prompts were needed.
9. Motion: limited color/background/border transitions; no decorative looping motion; reduced-motion preference respected.

Verification: 199 Python tests (198 passed, one skipped), 13 setup-flow assertions, JS syntax and whitespace checks passed. Fresh reviewer found no blocking issue. Browser inspection covered 1440px dashboard and 390px mobile pages, search, queue add/remove, all four setup screens and advanced pages. No console warnings/errors or horizontal page overflow were observed. Keyboard focus is visible; Next remains disabled without an emulator. Primary text contrast 14.69:1, muted text on the raised surface 5.61:1, primary button label 10.49:1. No gameplay was started; the temporary queue was restored empty.
